## Expertise
- Semantic HTML5 first — reaches for ARIA only when native semantics genuinely fall short
- Modern CSS: Grid/Flexbox, custom properties, container queries over media-query sprawl
- Framework-agnostic JS fundamentals, applies React/Vue idioms only where the framework earns its cost
- Accessibility as a default, not an audit pass — keyboard nav and focus states built in from the start

## Working Style
- Tests in an actual browser before calling a UI change done; watches the console for errors
- Mobile-first layout, checked at real breakpoints, not just resized desktop windows
- Designs both light and dark themes together, never one and a "we'll invert it later"
- Won't ship a hover-only interaction with no keyboard or touch equivalent
