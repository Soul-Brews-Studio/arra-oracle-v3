Merge — post-processing step, not real-time

On stop, orchestrator shells out to ffmpeg once: channel-merge (not sum) mic.wav + system.wav into a 2-channel file. No mixing logic inside the Swift capture binary.

Control mechanism

  1. Keyboard shortcut (Automator Quick Action, same pattern as projects/voice-to-terminal/toggle.sh) invokes toggle.sh.
  2. Not running → create ~/Documents/MeetingRecordings/<YYYY-MM-DD_HHMMSS>/, launch the Swift record-meeting binary in the background, write its PID to a pidfile.
  3. Already running → SIGTERM the PID, wait for clean exit, run the one ffmpeg merge command, remove the pidfile.

Not built here: transcription, cloud upload, Zoom/Meet/Teams API integration, diarization, retention policy, ACL, GUI. See PLAN.md for the full reasoning and open questions.
